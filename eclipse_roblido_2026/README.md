# Eclipse total de Sol — Roblido, 12 de agosto de 2026

Página web independiente (sin relación con PiFinder) sobre el eclipse solar total
del 12 de agosto de 2026, pensada para la gente de Roblido (A Rúa de Valdeorras,
Ourense, CP 32354) y, en general, para Galicia.

Es un único fichero autocontenido: `index.html`. Basta con abrirlo en cualquier
navegador; no necesita servidor ni conexión (la tipografía y los datos del mapa
van embebidos).

Contenido:

- Horarios de cada fase del eclipse calculados para Roblido (primer contacto,
  totalidad, máximo, fin) y cuenta atrás.
- Simulador interactivo de las fases tal y como se verán mirando al ONO.
- Mapa de Galicia con la franja de totalidad, el límite sur, las isolíneas de
  duración (30/60/90 s) y la duración por localidades, con tooltips.
- Gráfico comparativo de segundos de totalidad por pueblo, y tabla de datos.
- Consejos de observación (horizonte ONO despejado, seguridad ocular ISO
  12312-2, meteorología en Valdeorras, plan B).

Las horas y duraciones se calcularon geométricamente con Skyfield y las
efemérides JPL DE421 para las coordenadas de cada localidad; el perfil del borde
lunar puede variar la totalidad en ±5 s. Los valores son coherentes con los
publicados por el IGN (https://eclipses.ign.es/eclipse-total-sol-de-12-de-agosto-2026.html).
